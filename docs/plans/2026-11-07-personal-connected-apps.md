# 个人版 Connected Apps 与手机连接

连接器默认入口与扩展方式已由用户于 2026-11-08 修正，见
[扩展现有连接器](2026-11-08-connector-extension.md)。下文保留为初版设计记录，
其中“自备 Composio 项目作为默认入口”不再适用。

用户要求先完成开发，完整自动测试、浏览器截图、真实账号及手机验收后置。
本设计是个人 fork 的开发方向，不修改 DSH。

## Connected Apps

在原连接器页增加“更多应用”，使用自己的 Composio 项目连接应用账号。
原 MCP、邮件和连接器保持原路径；Composio 使用固定 SDK，动态读取应用目录、
创建托管授权链接、按用户作用域刷新账号，并支持多个账号和重新授权。

项目 key 写入 DS Bot secret store，scope 为空，不注入 Bot shell。
客户端只见 configured 和账号元数据。外部链接只接受 Composio HTTPS
授权域名，不复制 OpenMausBot 托管凭据。SDK 关闭遥测、日志和自动本地文件上传。

每个账号默认没有 Bot 授权；选择 Bot 后可设置只读或“修改前批准”。
Bot 经 `connected_apps`、`search_app_tools` 和 `execute_app_tool` 调用，
使用明确账号、工具版本和参数。服务端重新校验账号归属、工具所属应用、
当前授权及实际连接状态；未标记只读的操作走 DSH 原生单次审批。
停止、修改权限或断开账号会撤销待执行授权。SDK 的工具执行不自动重试；
超时结果不能当作未执行再次提交。

界面沿用现有主题、设置容器与表单。首屏回答“哪些账号能被哪些 Bot 使用”，
显示真实状态和明确错误。账号权限显式保存，断开与替换项目需要确认。
应用目录可搜索和分页，登录等待状态支持重新打开和刷新。
不增加虚构使用量或装饰性图表。截图和交互验收按用户要求后置。

## 手机

独立手机仓库 `payAgain/ds-bot-mobile-app` 负责原生界面、配对和 Tailscale
传输。DS-Bot 公开产品 API 负责消息归属、审批、问题、附件和工具能力准备。
手机不获得任意宿主管理 API，也不获得 Composio 项目 key。
新增操作必须绑定已配对设备、可见会话以及当前待决对象。

手机端继续使用已有 SDK 和组件；桥接层提供已实现能力后才开启相应功能。
文件须限制大小与类型、记录会话归属，下载不得接受客户端任意本机路径。
流式数据必须脱敏；重新连接后与持久消息协调，不重复显示或重复执行。

## 本轮交付边界

先提交源代码与生成的前端文件，不在运行中的个人 profile 验证变更。
构建与语法检查只说明代码可以生成产物，不代表真实 OAuth、远程账号动作、
手机安装、跨网络连接或审批已经验收。
