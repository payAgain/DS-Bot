# Bot 产品层系统提示词

用户授权的新功能：完整管理产品层的人设、表达风格与工作策略。只使用 DSH 插件 API，不修改 DSH。

## 层次与兼容

- DSH/供应商提示词、权限、工具能力、记忆与团队路由协议不属于可替换层。
- `promptMode` 为 `default` / `append` / `replace`；缺省按既有 instructions 是否非空解析，旧 Bot 拼装字节保持不变。
- `instructions` 保留追加说明；`systemPrompt` 单独保存完整自定义产品人设。切换模式不删除任一文本。
- 替换模式去除产品固定表达风格、进度表达与主 Bot 默认分工策略，使用用户完整文本。Bot 的实际名字、角色、团队路由、工具与权限规则保留。
- 模板只来自项目自有配置；预览只展示可编辑层，不展示模型请求、宿主隐藏指令或凭据。
- 存储沿用 roster 的 JSON 保存/重载；复制 Bot 携带模式及文本；create_bot/update_bot 支持同名字段。非主 Bot 仅能改自己。

## 编辑

独立卡片，明确保存/取消，不在失焦时写入。默认模式忽略但保留其他文本；恢复默认为草稿操作，保存后生效。替换模式非空、最多 50,000 字符。编辑中切换设置保留内存草稿，离开页面提示未保存。保存失败保留草稿。并发修改通过保存时比较原版本阻止覆盖。

设置在下一次模型请求组装时读取，适用于私聊和群聊；已发送请求不变，对话旧历史仍存在。更新沿用产品既有的配置通知流程。

## 验收

覆盖旧默认与追加兼容、替换不残留默认风格、恢复默认、复制、存储重载、非法/空值原子拒绝、权限、并发保存；运行项目全量单测、构建检查、lint 与 mock smoke；真实浏览器检查设置操作。部署 host 需要协调空闲窗口，开发测试不修改真实 Bot 人设。

## 集成

隔离工作树从当前个人分支 HEAD 加现有未提交产品修改建立，保留 Mac管家连接器改动。集成只取本功能增量，然后重新生成 client.js；不覆盖现有发布包。
