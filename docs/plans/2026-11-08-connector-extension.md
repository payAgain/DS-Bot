# 扩展现有连接器

2026-11-09，用户进一步要求去掉自动化选择，全部默认自动执行。账号页面移除
权限下拉框，仅保留账号启用和 Bot 授权。新旧扩展账号统一自动执行，历史
`read`／`ask` 按自动权限处理；兼容旧客户端保留返回字段 `mode: auto`，保存
授权时统一写入 `auto`，旧客户端传入的权限选项不再改变执行行为。此决定
替代紧接下方“增加第三个权限选项”的方案。账号停用、Bot 范围、账号归属、
工具应用归属、执行前复查和不自动重试的规则继续适用。

2026-11-09，用户明确要求增加适用于定时任务的「全自动」权限，并继续使用
现有连接器。账号权限在原下拉框增加 `auto`：所选 Bot 可执行读写操作，无需
逐次审批。`read` 和 `ask` 含义、已有保存值及新账号默认值保持原有规则。
这替代下文“未标记只读的动作必须单次审批”的限制：只有 `ask` 仍逐次审批，
`read` 拒绝写入，`auto` 使用用户保存的账号及 Bot 授权。停用、移除 Bot、
降级权限、断开或替换项目继续立即撤销尚未发出的操作。全自动适用于托管与
自备项目两条现有路径；原生 MCP 与邮箱连接器继续使用自己的已有设置。

用户于 2026-11-08 明确要求：在 DS-Bot 原生连接器上扩展 OpenMausBot 官方客户端
提供的连接能力，用户从同一个连接器列表选择服务并重新授权，不迁移原有账号。
本决定替代前一设计中将自备 Composio 项目作为默认入口的部分。

## 界面和接入

现有 MCP、邮箱和自定义连接器继续使用原来的目录与工具链。主连接器页在同一个
搜索框下加载扩展应用目录；不再要求先进入“更多应用”填写项目密钥。
已有原生目录中的同名应用不在扩展列表重复出现。
自备项目保留为“连接服务设置”里的可选高级配置。
该入口先在网关进程验证项目密钥，成功后才保存；Windows 浏览器与本机浏览器
使用同一套所有者接口。界面明确显示是否已在当前网关保存。最近一次保存尝试的
验证/写入阶段、时间及安全错误说明保留在运行时状态中，失败也进入脱敏诊断，
不记录密钥、请求体或浏览器会话凭据。网关重启后已保存项目继续有效，
最近尝试状态重置；不以运行时诊断代替持久化配置。

默认适配 OpenMausBot 的托管连接服务协议，通过公开注册接口生成新的独立安装身份，
不读取 OpenMausBot 本机的密钥或已连接账号。安装凭据保存在 DS-Bot secret store，
scope 为空，不返回浏览器、不进入 Bot shell。服务地址可通过插件配置
`connectedAppsService` 指向同协议的自有服务；必须使用 HTTPS，测试夹具可用回环 HTTP。
服务拒绝访问时如实显示 HTTP 错误，保留原生连接器，不规避服务限制。
按上游 `server/composio.ts` 的做法，在线目录失败时仍展示源码中的 24 个常用应用，
明确标记为内置目录，并禁用授权入口；显示目录不表示已接通对应服务。
在线目录逐页读取并去重，在同一安装实例内缓存十分钟，搜索覆盖所有已读取页，
前端每页展示四十条。游标重复、页码停滞、数量不符和请求失败均标为不完整目录。

上游 `src/lib/hosted-mcp-apps.ts` 中的 Whop、Agentcard 使用各自官方 MCP 地址，
直接加入 DS-Bot 的原生连接器目录，沿用已有 MCP OAuth、Bot 权限和审批机制，
不经过 Composio 服务。邮箱、X、Postiz、HighLevel 等专门实现需分别评估；
不能把 Composio 适配视为移植了 OpenMausBot 的所有连接器。

## Bot 使用

扩展连接器加入 `list_connectors` 和 `request_connector` 的现有发现与请求流程。
授权账号仍需明确选择允许使用的 Bot。具体工具沿用
`connected_apps`、`search_app_tools`、`execute_app_tool`。

托管 MCP 返回的工具发现结果只能用于同一应用、同一账号，缺少只读声明的动作
必须经过 DSH 单次审批。执行前重新验证权限和当前账号；发现引用只代表本次工具
发现，不声称锁定了上游工具版本。失败的执行不自动重试。

当前托管适配器尚未实现具体账号 ID 与执行请求的显式绑定。因此每个应用仅允许一个有效账号
参与工具执行；检测到多个有效账号时拒绝执行，不能默选其他账号。

## 验证范围

本地协议夹具覆盖安装注册、目录、全新授权、账号回查、工具发现、权限审批、
断开和不重试行为；真实服务验收与夹具验证分开记录。2026-11-08 当前主机访问
官方服务 `/health` 得到 Cloudflare HTTP 403、错误码 1010，尚未取得真实目录，
不能据本地测试宣称真实官方服务已连通或 OAuth 已完成。
