# 全权托管执行

2026-11-09 用户明确要求：所有任务都自动执行，不仅是连接器或定时任务；仅在缺少用户意图、决定或必须由用户本人完成确认时询问。

- 支持 `danger-full-access` 的 DSH 上，Bot 默认使用完全权限。已有 Bot 没有单独设置时也使用该默认；用户明确设置的较低权限和群权限继续生效。
- 每次模型执行前使用公开的权限服务同步 Bot 会话，覆盖普通对话、群任务、定时任务、恢复的会话和后续对话段。本地 Agent 使用同一有效权限。
- DSH 的 `approval: never` 表示直接拒绝审批请求，不代表自动允许。全权托管会话保持完全沙盒权限，并通过公开的 `approval: ask` 服务将请求交给 DS Bot 的会话范围应答器；技术执行请求自动允许，仍保留 DSH 审计记录。
- 切换到完全权限后，当前会话中已经等待的技术审批自动完成。取消的请求不能恢复；非 Bot 会话和较低权限会话不自动批准。
- 明确需要用户决定的内容与技术权限区分。私密 Bot 对外分享的确认保留为用户决定，`ask_user`、安全输入密钥、登录及付款交接继续使用已有流程。
- 连接器账号启用状态、Bot 授权范围、隐私隔离、Bot 管理角色及操作去重保持原有边界。仅使用公开 DSH 插件接口，不修改 DSH。
